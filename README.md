# One Word From Grandma

**Winning entry word:** `robit`

A typo a grandma would actually make for "robot" — warm, funny in one word, and unmistakably about AI/robots without being the obvious "robot" itself.

## Run instructions

```
python3 repo/main.py
```

The program validates the word (1–30 characters, single word, not only whitespace), writes it to `/output/entry.txt`, and prints it to stdout.
